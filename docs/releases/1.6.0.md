# 微信 AI 助手（WeChat AI）v1.6.0

macOS 原生微信 AI 助手：通过 Frida Gadget 注入本机官方微信，把消息桥接到 SwiftUI App，
由 DeepSeek / OpenAI 兼容模型生成回复。修改微信客户端存在账号风控与签名失效风险，
请先阅读风险说明并备份。

## 本版重点

- **多微信账号数据隔离**：按当前登录的微信账号自动切换聊天记录、长期记忆、会话设置、
  机器人配置、人格、定时任务与新媒体目录；切换后各账号数据互不可见。
- **全局共享能力**：AI 通道/Keychain、Hook、OneBot、语音模型与音色库、CosyVoice、崩溃日志、
  bridge 日志与微信备份不随账号切换。
- **旧版迁移**：旧单库按 `onebot.self_id` 归入对应账号；使用 SQLite Backup API 生成一致快照，
  旧库、旧 `config.json`、旧媒体目录全部保留；迁移幂等，不覆盖已有账号数据。
- **切号行为**：启动、启动机器人前、运行中登录不一致都会识别；运行中换号会先停止机器人，
  切库后需手动重新启动。未识别账号时使用 `_unassigned/`，首次登录后复制认领并保留原目录。
- **设置 → 数据与备份**：显示当前账号 mask、账号目录、数据库、媒体、全局配置/备份/日志目录；
  可「重新检测微信账号」。不提供手动选择数据库/账号档案。
- **升级提示**：旧聊天只有在切回原微信账号后可见；首次升级需要与旧库同量级额外磁盘空间。
- 保留菜单栏左键面板、语音回复免延迟、CosyVoice3 / Kokoro 103 音色、语音转写/发送、
  图片获取与识图、引用机器人、群聊身份约束、唤醒窗口等功能。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，
   或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. 这是**菜单栏 App**：启动后看屏幕顶部菜单栏图标，**左键单击开合状态面板**。
   可在「设置 → 通用」关闭 Dock 图标，改用菜单栏入口。
4. 首次向导（右上角可切换 **语言 / Language**）：环境检查 → 检测微信 → 完全退出微信后备份并
   安装 Hook → 配置 AI → 启动。安装 Hook 需要 Xcode Command Line Tools；向导可检测与引导安装。
   安装后需手动打开并登录微信；拒绝「App 数据」授权会导致图片/语音相关功能失败。

完整步骤与常见问题见仓库 [`install.md`](../install.md)。

## 包含内容

- SwiftUI App（菜单栏、设置、会话、人格、记忆、定时任务、日志、语音、识图、CosyVoice 管理）
- Go OneBot bridge（`Contents/Resources/bridge/onebot`）与同步的 `script.js`
- Frida Gadget 17.8.0（`Contents/Resources/hook/gadget/FridaGadget.dylib`）
- Hook 版本表（含 4.2.0.9 / 4.2.0.5 / 4.1.15.55 / 4.1.12.53）
- 本地语音所需的 sherpa-onnx 静态库与 SILK 编码依赖
- CosyVoice3 安装/启动脚本与 HTTP sidecar（不含模型/音色）

## 已知限制

- 旧版数据迁移只在首次升级时执行；旧聊天需切回原微信账号查看。迁移前建议备份
  `~/Library/Application Support/WeChatAI/` 与微信聊天数据。
- R3 仅支持文本；首次使用或微信重启后需在本机手动发一条消息捕获发送句柄；
  语音首次启用或微信重启后还需发一条语音捕获句柄。
- CosyVoice3 CPU 推理偏慢，不是实时 TTS；启动约 30–90 秒，常驻内存约 8–9 GB。
- 识图需要支持 `image_url` 的视觉模型；图片获取只处理实时入站图片。
- 4.2.0.9 的语音发送、媒体下载、群聊 @ / 拍一拍本轮未复测。
- 仅适配 4.2.0.9 / 4.2.0.5 / 4.1.15.55 / 4.1.12.53；微信升级后可能失效，可用备份还原。
- 身份约束是提示词级软约束，模型仍可能不遵守；关键人物关系建议写入手写核心记忆。

## 安全与许可

- 仅在自己的设备与账号上使用；不要用于他人账号或绕过风控。
- 修改微信官方 App 会破坏签名，存在账号风险与数据丢失风险；安装前请自行备份聊天数据。
- App 为 ad-hoc 签名、未公证；只从本仓库或你信任的发布者获取二进制。
- **App/仓库不包含任何音色参考音频、`voices.json` 或私有音色生成脚本**；音色只存本机。
- 账号数据库、`account-state.json`、`profile.json` 与媒体只存在本机，不进入仓库或 Release 包。
- 项目遵循 GPL-3.0，源码与对应修改见仓库；分发二进制时请保留许可证与 `bridge/NOTICE`。
